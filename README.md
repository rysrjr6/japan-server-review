## 为什么日本服务器测评要看线路而不是只看CPU

很多人打开测评文章第一眼找的就是CPU型号、内存大小、硬盘容量。这些当然重要，但日本服务器真正拉开差距的，是**回国线路**。

日本机房到中国大陆的物理距离不远，东京到上海直线距离不到1800公里，理论上延迟应该很低。但实际体验差异巨大，原因就在于国际出口线路的选择。

目前日本服务器常见的回国线路大致分几类：

- **CN2 GIA（AS4809）**：电信精品网络，独立回国通道，晚高峰拥堵少，延迟稳定在60-120ms，是日本服务器里最稳的一档
- **CN2 GT**：电信普通CN2，比普通BGP好，但高峰期仍有波动
- **SoftBank（软银）**：联通用户访问日本机房速度很快，是仅次于CN2的优质线路
- **普通BGP**：走国际公共出口，晚高峰容易拥堵，延迟波动大
- **IIJ、NTT、KDDI**：日本本地运营商，国际方向稳定，但回国需要看是否接入CN2

恒创科技的日本节点部署在东京Equinix TY8机房，接入的是KDDI+SoftBank+IIJ+NTT构建的全穿透动态BGP网络，同时叠加CN2 GIA（AS4809）高速回国通道。这个组合的意思是：日本本地访问走BGP，中国方向走CN2 GIA，两边都有优化。

## 日本服务器测评里最容易被忽略的三个指标

除了延迟和带宽，还有三个指标在测评里经常被一笔带过，但实际使用中影响很大。

**晚高峰丢包率**。很多日本服务器白天延迟漂亮，一到晚上8-11点就开始丢包。普通BGP线路晚高峰丢包率能到5%以上，CN2 GIA线路因为有独立回国通道，晚高峰丢包率通常控制在1%以内。恒创日本节点走CN2 GIA，第三方测评显示三网晚高峰表现相对稳定。

**回程路由**。去程（中国到日本）和回程（日本到中国）可以走不同线路。有些商家去程走CN2，回程走普通BGP，实际体验会打折扣。判断方法是用BestTrace或MTR做路由追踪，看回程是否经过59.43.x.x节点（CN2骨干网标志）。

**IP纯净度**。日本服务器IP分原生IP和广播IP两种。广播IP是从其他地区广播到日本机房使用，价格便宜但可能被日本本地服务识别为非日本地区。原生IP是真正属于日本本地的IP段，解锁Netflix、Disney+、AbemaTV、TVer等日本流媒体成功率更高，做日本跨境电商账号也更安全。
